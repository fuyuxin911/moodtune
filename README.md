# MoodTune

一个纯前端的「情绪 × 音乐 × 可视化」互动作品集项目。音频文件不会上传：它只在浏览器本地播放和分析。

## 已完成的第二阶段功能

- 多文件本地播放列表：支持 MP3、WAV、OGG、M4A，可点选、删除、上一首、下一首。
- 自动读取浏览器可取得的时长；MP3 会尝试读取轻量的 ID3v1 标题、艺术家与专辑信息，其他情况回退为文件名。
- 顺序播放与循环播放，歌曲结束时自动切换。
- 真正的 Web Audio API `AnalyserNode` 分析：频率数据和时域波形会实时驱动画面。
- 频谱柱、圆形频谱、波形三种可切换的可视化模式。
- 基于低频、中频、高频、整体音量的平滑动画反馈；每种 Mood 都有可独立调整的配置参数。
- localStorage 保存 Mood、模式、音量、播放模式与最近播放记录（不会保存本地音乐文件）。
- 快捷键：`Space` 播放／暂停、`←`／`→` 切歌、`M` 静音、`1`－`5` 切 Mood、`V` 切换可视化。

## 运行方式

不需要安装 Node.js、npm、Python 或任何依赖。

1. Windows 上请直接双击 `启动 MoodTune.bat`；它会用你的默认浏览器打开页面。也可以右键 `index.html`，选择“打开方式”→ Chrome 或 Edge。
2. 选择一个心情，在左侧「我的音乐」点击上传，选择一个或多个音乐文件。
3. 点击播放；在舞台左上角切换频谱、圆形或波形模式，移动鼠标和画面互动。

如果浏览器阻止本地音频或字体加载，可以在项目目录启动一个简单的静态服务器后访问页面。例如已安装 Python 的电脑可运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。如果系统没有 Python，不需要安装它；使用 `启动 MoodTune.bat` 即可使用本项目。

## 项目结构

- `index.html`：参考图风格的侧栏、播放列表、舞台、播放器和快捷键说明。
- `styles.css`：桌面端沉浸式场景、柔和像素感配色和播放器布局。
- `app.js`：集中式播放器状态、本地文件播放、播放列表、Web Audio API 分析、Canvas 动画、本地设置与错误处理。
- `启动 MoodTune.bat`：Windows 双击启动入口。
